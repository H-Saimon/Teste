## ⚙ Como Executar o Projeto

1. **Clone o repositório:**

```bash
git clone https://github.com/H-Saimon/Teste.git
cd Teste
```

2. **Instale as dependências:**

```bash
npm install
```
*ou*

```bash
yarn install
```

3. **Execute o projeto:**

```bash
npm start
```
*ou*

```bash
yarn start
```

4. **Acesse a aplicação:**

Abra o navegador em `http://localhost:3000` (ou a porta configurada).
